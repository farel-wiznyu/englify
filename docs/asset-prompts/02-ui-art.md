# UI art: avatars, results, badges, game icons, app icons

> Kerjakan satu kelompok kecil per chat ChatGPT: tempel STYLE BIBLE sekali di awal, lalu tempel prompt satu per satu (satu gambar per pesan). Setelah sekitar 8 gambar, buka chat baru dan tempel STYLE BIBLE lagi.
> Item Ollie (icon, android-icon-foreground, android-icon-monochrome, splash-icon): lampirkan gambar referensi Ollie di chat itu sebelum menempel prompt-nya, dan lampirkan lagi di setiap chat baru.
> Semua gambar 1024x1024 transparan, kecuali icon (1024x1024, opaque) dan memory-card-back (512x512, opaque). Kalau ChatGPT tetap memberi latar, ulangi dengan "on a flat solid #FF00FF magenta background" lalu hapus magenta-nya.
> Urutan yang disarankan: 6 avatar, lalu trophy/balloon/medal, 6 badge, 4 ikon game, terakhir 4 ikon aplikasi.
